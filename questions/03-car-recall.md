# Is there a recall on my car

Topic: cars. Formats asked: quick question. Task id: F-B-04.

## The question as asked

### Quick question

The users who answer when asked, give the bare minimum, or are vague opened with:

> Is there a recall on my car?

The user who gives everything up front opened with:

> Is there a recall on my car? it's a 2019 subaru outback 2.5i, bought used, and i'm in minneapolis. i don't have the vin handy. i want to know about safety recalls, from the official source.

## What the simulated user knew

- The car is a 2019 Subaru Outback 2.5i, bought used.
- The user does not have the VIN to hand.
- The user lives in Minneapolis, Minnesota.
- The user wants to know whether any open recall applies. A good answer lists the recalls for that model year or says how to check by VIN.
- The question is about US safety recalls on the 2019 Outback.
- The user wants a short answer.
- The user wants the official source, NHTSA or Subaru.
- The user wants current information.

## Answer key

NHTSA's recall database returns three recalls for the 2019 Outback. Each covers "certain" vehicles, so a given VIN may not be affected. Source for all three: [NHTSA recalls by vehicle, 2019 Subaru Outback](https://api.nhtsa.gov/recalls/recallsByVehicle?make=subaru&model=outback&modelYear=2019), read 2026-09-24.

1. Recall 19V493000: spot welds on the duct below the cowl panel may have been applied wrongly, weakening the body structure.
2. Recall 20V218000: the low-pressure fuel pump may stop working.
3. Recall 21V587000: a second campaign on the same low-pressure fuel pump defect.

New recalls can be added at any time.
