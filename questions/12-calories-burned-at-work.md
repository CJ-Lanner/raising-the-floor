## What the simulated user knew

- The user is 5'6", 140 lb, 29 and female.
- The user works as a cashier and packer at a fast-food restaurant, on their feet for the whole 8-hour shift, walking short distances and lifting light boxes.
- The user tracks calories in MyFitnessPal.
- The user wants a per-shift estimate of the work movement only, not resting metabolism.
- The user wants a short answer with the math shown.
- The user wants the Compendium of Physical Activities or an equivalent, and the MET value used. A MET is a measure of how much energy an activity burns compared with sitting still.
- The user does no other exercise that day.

## Answer key

The 2024 Adult Compendium has no code that says "cashier". All values below come from the [2024 Adult Compendium PDF](https://pacompendium.com/wp-content/uploads/2024/03/1_2024-adult-compendium_1_2024.pdf), read 2026-09-24.

1. Code 11600, standing tasks, light effort (store clerk and similar): 1.8 METs. Occupation table, page 14.
2. Code 11610, standing, light to moderate effort (includes packing boxes): 3.3 METs. Code 11615, standing, moderate effort, lifting 10 to 20 lb continuously: 4.5 METs. Occupation table, page 14.
3. Code 17016, walking while carrying a 5 to 14 lb load, level ground, moderate pace: 4.0 METs. Walking table, page 21.
4. Code 17152, walking 2.0 to 2.4 mph: 2.8 METs. Code 17170, walking 2.5 mph: 3.0 METs. Walking table, page 22.
5. The older 2011 Compendium gives different values for two codes: 11600 was 3.0 METs (1.8 in 2024), and 11610 was 3.0 (3.3 in 2024). Codes 17152 and 17170 are unchanged. Source: [2011 Compendium supplement, Ainsworth and others, Medicine and Science in Sports and Exercise, 2011](https://cdn-links.lww.com/permalink/mss/a/mss_43_8_2011_06_13_ainsworth_202093_sdc1.pdf), read 2026-09-24.

Grading rule: the key is the 2024 Compendium. A reply that cites a 2011 value that differs from the 2024 value fails the check, because it rests on an out-of-date source. Where the two editions agree (17152 and 17170), the edition does not matter.
