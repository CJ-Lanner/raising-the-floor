# A part list for a first PC build

Topic: shopping. Formats asked: detailed request. Task id: D-F-22.

## The question as asked

### Detailed request

The users who answer when asked, give the bare minimum, or are vague opened with:

> I want to build my first PC, mainly for 1440p gaming and some video editing. Budget is $1,500 for the tower only, I already have a monitor and peripherals. I'd like a full part list with current prices that fits the budget, plus links to a couple of well regarded build guides or videos so I can actually put it together. Prefer PCPartPicker or reviewer sites like Gamers Nexus for parts, not affiliate 'best builds' posts. The list plus the resources is enough, no essay.

The user who gives everything up front opened with:

> I want to build my first PC, mainly for 1440p gaming and some video editing. Budget is $1,500 for the tower only, I already have a monitor and peripherals. I'd like a full part list with current prices that fits the budget, plus links to a couple of well regarded build guides or videos so I can actually put it together. Prefer PCPartPicker or reviewer sites like Gamers Nexus for parts, not affiliate 'best builds' posts. The list plus the resources is enough, no essay. new current gen parts from us retailers, no brand preference. quiet would be nice but not essential.

## What the simulated user knew

- The PC is mainly for 1440p gaming and some video editing.
- The budget is $1,500 for the tower only. The user already has a monitor and peripherals.
- The user wants a buildable part list for those uses, plus resources to put it together.
- Only new, current-generation parts from US retailers.
- The user wants the list and the resources, no essay.
- The user wants PCPartPicker or reviewer sites for parts, and wants affiliate build posts flagged.
- The user wants current prices.
- The user has no brand preference. Quiet would be nice but is not essential.
- The answer should be a list with prices and a total, then the resources.

## The checklist

A good answer had to meet every check. A check that fits the person's situation tests whether the answer used the user's own facts. A check that gets the facts right tests whether the answer is right about the world.

| # | Check | Kind | Checked against |
|---|---|---|---|
| 1 | The reply's own total for the parts in the build (or, if it gives none, the sum of its listed prices) is $1,500 or under, and those parts cost no more than $1,550 when the grader looks them up (one logged lookup per part; a PCPartPicker list link counts). An item the reply marks optional, such as an operating system license, is left out of the total. | Fits the person's situation | A lookup per part |
| 2 | The parts are compatible: the CPU socket matches the board, the RAM type matches the board, and the power supply's wattage covers the graphics card maker's minimum. | Fits the person's situation | A lookup per part |
| 3 | Every part named is currently sold, not discontinued. | Gets the facts right | A lookup per part |
| 4 | At least two named build resources exist and are what the answer says they are. | Gets the facts right | A lookup per resource |

## Answer key

There is no fixed answer key beyond the lookups. The grader read compatibility from the makers' spec pages.
