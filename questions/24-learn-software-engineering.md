# A free program to learn software engineering

Topic: school. Formats asked: detailed request. Task id: D-F-26.

## The question as asked

### Detailed request

The users who answer when asked, give the bare minimum, or are vague opened with:

> I'd like to learn software engineering properly, starting from almost zero, with the aim of building web apps and maybe changing careers in a couple of years. I can put in about 10 hours a week. Which free, well regarded program should I follow, and can you turn it into a rough 6-month plan? I'm thinking something structured, at the level of The Odin Project or CS50. I'd like to see the actual resources you're recommending, with sources like reviews from people who finished them, not a plan made up on the spot.

The user who gives everything up front opened with:

> I'd like to learn software engineering properly, starting from almost zero, with the aim of building web apps and maybe changing careers in a couple of years. I can put in about 10 hours a week. Which free, well regarded program should I follow, and can you turn it into a rough 6-month plan? I'm thinking something structured, at the level of The Odin Project or CS50. I'd like to see the actual resources you're recommending, with sources like reviews from people who finished them, not a plan made up on the spot. it needs to be self paced, beginner friendly, and still maintained. not a bootcamp and not a degree. no language preference. a month by month plan for the six months.

## What the simulated user knew

- The user is starting from almost zero, aims to build web apps, and may change careers in a couple of years.
- The user can put in about 10 hours a week.
- The user wants one structured free program and a 6-month plan toward building web apps.
- The program must be free, self-paced, beginner-friendly and still maintained. No bootcamps and no degrees.
- The user wants a pick, then a rough month-by-month plan.
- The user wants reviews from people who completed the program, and wants the program's own marketing flagged.
- The user has no language preference and will use whatever the program uses.

## The checklist

A good answer had to meet every check. A check that fits the person's situation tests whether the answer used the user's own facts. A check that gets the facts right tests whether the answer is right about the world.

| # | Check | Kind | Checked against |
|---|---|---|---|
| 1 | The program is free and structured for beginners, per its own site. | Fits the person's situation | A lookup of the program named |
| 2 | The plan is sized to about 10 hours a week over 6 months and targets web apps. | Fits the person's situation | The conversation |
| 3 | Every program the reply tells the user to follow exists and is free to use. A paid option the reply clearly marks as optional, or names only to rule out, does not count. | Gets the facts right | A lookup per program named |
| 4 | The answer cites at least two external sources about the program. A plan built with no sources fails. | Gets the facts right | The conversation |
